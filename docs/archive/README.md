# 历史资料

本目录保存已结束、被替代或固定时期的方案、实施记录、实验结果和会话快照。归档表示退出日常维护，资料仍可用于理解设计原因和追溯历史。

## 归档边界

- 实施任务已结束，结果已进入当前规则与流程。
- 旧版本已被明确替代。
- 文档只描述一次实验或一个时期的状态。

尚未定案的需求、未完成的当前任务和仍使用的运维手册不因日期较早而归档；持续维护的资料有局部过期内容时应先校准。归档文档中的旧字段、接口、分支、运行状态和授权表述不能直接转成新任务。

当前入口为 [PRD](../product/PRD.md)、[当前任务](../product/教学模块开发任务清单.md)、[架构规则](../product/education.md)、[Userflow](../product/教学模块Userflow.md) 与 [本地开发](../development/local-development.md)。

## 历史内容

- [教学模块开发记录](教学模块开发记录.md)：旧总任务的已实现、冲突和废弃结果。
- [提交前质疑开发清单](提交前质疑环节开发任务清单.md)：首次实现记录。
- [质疑增强与教研分析清单](质疑环节增强与教研分析开发任务清单.md)：后续实施、下线与否决记录。
- [修订初稿方案](哈工深修订初稿方案.md)：课程背景和当时的设计与实施依据。
- [压测记录](压测记录.md)：旧测试条件、结果和限制；运行方法见 [压测工具](../../scripts/loadtest/README.md)。
- [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md)：早期上游架构介绍。
- [SESSION_HANDOFF.md](SESSION_HANDOFF.md)：历史会话快照。

历史专题中的 PRD 章节编号属于其开发时期，不保证对应当前 PRD；旧版原文从 Git 历史追溯。作业归档、风险汇总、消化度等旧要求不恢复为待办。

本目录中尚未纳入 Git 的手册仍待确定正式源文件和发布方式，不因目录位置自动判定弃用，也不在本次整理中删除。
