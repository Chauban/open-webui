## 与当前实现冲突的旧要求

| 原要求或描述                                        | 当前边界                                                                                      | 处理结论                                       |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| 新增作业 `status / archived_at`、归档接口与归档操作 | `Assignment` 无这两列，无作业归档流程                                                         | 已删除，不恢复，不作为待办                     |
| 按作业取提交列表的旧教师接口                        | 全局与作业内列表复用教师队列                                                                  | 更新接口引用，不重建旧接口                     |
| 单独班级作业子页                                    | 班级仅总览、学生；作业入口指向全局列表的班级筛选                                              | 不恢复子页面                                   |
| 任意编辑评分和作业形式                              | 首次提交锁定满分及维度；有基线或提交锁定作业形式                                              | 将锁定作为验收条件                             |
| 所有实例默认允许退回                                | `education.enable_return` 默认关闭，前后端共同控制                                            | 未显示按钮不等于缺陷                           |
| 成长画像保留消化度、平均改写率和固定 AI 用途迁移    | 旧指标已删除；提问与反思质量由教师评分                                                        | 不沿用旧指标清单                               |
| 提问条数或反思字数直接代表质量                      | 条数只作参考，未评分保持空值                                                                  | 不添加计数评分或兜底分                         |
| 产出维只显示原分，不提供跨满分的比较口径            | 模型及画像已有 `normalized_score` 与 `average_score_percent` 等百分比口径，同时保留原分、满分 | 不能遗漏已有比较口径，百分比不等于新增合成指数 |
| 批量导入直接创建未注册账号                          | 班级导入匹配已存在账号，缺失账号失败                                                          | 不宣称具有批量开户能力                         |
| “CSV 或 XLSX”意味着两种格式都需实现                 | 当前 CSV 已满足原文的任选格式要求                                                             | XLSX 没有自动新增为待办                        |
| 原拟议 API 名称和旧响应字段                         | 当前以真实路由与严格模型为准                                                                  | 不为文档兼容旧协议                             |
| 班级、作业的风险加总和未定学生审批形态              | 过程信号逐份核查；有效邀请码学生注册后激活，教师需管理员批准                                  | 风险加总已废弃，审批规则已确定                 |
