# RightWrite Branding Boundary

This project is branded to users as **RightWrite**.

## Product Brand

Use `RightWrite` for user-facing product surfaces:

- Browser titles and PWA names
- Login, onboarding, sidebar, splash, and error screens
- Notification titles and icons
- Manifest and OpenSearch descriptions
- Default product icons, app icons, and fallback profile/model images

## Upstream And Community References

Keep `Open WebUI` where the text refers to upstream ecosystem or compatibility:

- `Open WebUI Community`
- Plugin, tool, prompt, model, or function community source labels
- Compatibility fields such as `required_open_webui_version`
- Upstream ownership, support, funding, or project-origin notes

## Internal Technical Names

Do not rename internal implementation identifiers only for branding:

- Package and module paths such as `open_webui`
- Existing API paths and route names
- Existing config keys such as `WEBUI_NAME`
- Database fields and migration names

Internal names can change only when there is a functional reason beyond visual branding.
