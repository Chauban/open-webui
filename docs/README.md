# Right Write 项目文档

本项目是基于 Open WebUI v0.11.2 的成长写作教学平台。当前规则、操作说明和共享工具随代码维护；历史资料用于追溯。

## 开始开发

1. 阅读根目录 [AGENTS.md](../AGENTS.md)，了解工程规则和业务边界。
2. 按 [本地开发说明](development/local-development.md) 准备环境并启动。
3. 修改教学功能前阅读 PRD、架构规则和当前任务清单，具体操作流程见 Userflow。
4. 提交前按 [Git 协作规范](development/git-workflow.md) 检查修改和同步状态。

## 需求来源与历史资料

[哈工深需求原文](product/sources/哈工深需求.txt) 是“写作课 AI 教学系统研讨”的导出逐字稿，2026-10-09 整理入库，原文保持不变。它记录教师的教学目标、场景和设计理由；发言中的设想及未定事项不直接作为当前要求，实施前对照 PRD、架构规则和代码。相关设计过程见 [修订初稿历史方案](archive/哈工深修订初稿方案.md)，实例配置从部署工具 README 查找。

- [历史文档](archive/README.md)：已结束或被替代的设计、实施记录和会话快照。`superpowers/` 中的既有计划也用于追溯。
- [开发记录](archive/教学模块开发记录.md)：旧总任务的已完成结果和冲突、废弃条目。
- [压测记录](archive/压测记录.md)：测试条件、实测数据及测量限制；运行方法以工具 README 为准。

`archive/` 保存退出日常维护但仍有追溯价值的资料。当前 PRD、Userflow 和待办在 `product/` 维护，运维记录在 `deployment/` 维护；不能只因日期较早或局部过期就整份归档。旧版本和临时过程由 Git 历史追溯。

## 仓库与同步范围

`open-webui/` 是唯一的代码 Git 仓库，外层 `right_chat/` 不是 Git 仓库。

- `src/`、`backend/`、`static/`：应用代码和静态资源。
- `scripts/`：开发和测试工具，其中 `loadtest/` 保存三个压测脚本及其 README。
- `deploy/`：部署脚本、systemd、Nginx 等服务器文件副本。
- `docs/`：开发说明、产品规则、部署实例记录、原始需求和历史资料。
- 根目录保留工具要求的配置、许可证、包管理清单、`AGENTS.md` 和两个 Windows 启动脚本。

以上共享规范、文档、脚本、配置模板和正式静态资源随仓库同步。构建工具需要的根目录文件继续放在原位置。

密钥、实际环境文件、数据库及备份、上传文件、向量库、依赖、虚拟环境、构建产物、缓存、日志和本机工具状态不入库。`.env.example`、品牌静态资源和 Pyodide 锁文件属于共享资源，按既有规则维护。

外层保留完整 `CLAUDE.md`、要求读取仓库规范的 `AGENTS.md` 和两个双击启动入口；启动逻辑在仓库维护。外层行政资料、真实学生材料、品牌源素材、手册、截图和个人配置仍单独管理，不能把“仓库已同步”描述成“整个工作区已同步”。当前文档统一从此索引查找，不在外层恢复重复副本。
