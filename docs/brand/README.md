## 色彩与字体

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 墨蓝 Ink | `#20406A` | 主文字、笔画与主要操作 |
| 深墨 Deep | `#15314E` | 墨色渐变深端 |
| 珊瑚 Coral | `#FF6A45` | Write 字标、强调与图标背景 |
| 浅珊瑚 | `#FFB199` | 深色背景强调 |
| 纸 Paper | `#F7F3EA` | 页面背景、反白文字 |

字标为 EB Garamond（Right Regular、Write SemiBold Italic，交付方标注 SIL OFL）。标题优先使用思源宋体 / Noto Serif SC，正文优先使用思源黑体 / Noto Sans SC。未随包提供字体文件；独立维护页使用本地字体栈，缺少指定字体时回退到系统宋体与黑体，不请求在线字体。

## 使用规则

1. 页眉优先使用横版字标；主标志优先使用渐变版。
2. 深色或珊瑚背景使用反白版。不倾斜、不拉伸、不改色。
3. 标志四周留白至少为图标高度的 50%；保证与背景的对比度。
4. 网页资源使用 `/brand/rightwrite/svg/…` 或对应 PNG 路径，不直接引用工作区外层文件。
5. 维护页 `deploy/maintenance.html` 将正式横版字标、渐变标志和珊瑚 App 图标原始 SVG 以 Base64 data URI 内嵌，保证停机时无需额外请求。更新这三份 SVG 时，同步替换维护页中 `.brand`、`.mark` 和 favicon 对应的 data URI；保持原始 SVG 内容与比例，不手工重画字标。

当前已接入升级维护页和应用弹窗系统。其余页面视觉迁移按具体任务处理；正式素材统一从本目录查找。

## 弹窗与提示（2026-11-12）

- 轻提示、操作确认、内容弹窗共用墨蓝 / 纸色视觉；样式唯一来源是 `src/lib/styles/overlays.css`，不在业务页面复制容器样式。
- 内容面 `#FFFFFF`、正文 `#253448`、次要文字 `#647084`、边线 `#DCE2E9`；危险操作 `#B53F3F`，深色模式使用对应高对比变量。珊瑚色不用于大面积主按钮。
- 标题使用品牌宋体栈 20px / 1.5，正文使用黑体栈 14px / 1.7；本地字体回退，不新增在线字体请求。
- 内容弹窗使用 `common/Modal.svelte`，优先传入 `title`、`description`，正文放默认插槽、操作放 `footer` 插槽。标题 / 操作区固定，长正文滚动。确认框宽 480px，常规内容宽 672px，宽内容 896px / 1120px；窄屏距边 12px。
- 圆角 18px（窄屏 14px），标题与正文横向留白 24px（窄屏 20px），按钮高至少 40px、圆角 10px。主操作靠右，取消在左；删除 / 移除使用危险色，标签写出动作。
- `ConfirmDialog` 复用 `Modal`；业务内顺序确认使用组件实例 `ask()`，取消和组件卸载返回 false，不使用 `window.confirm()`。长提示词使用纯文本展示，正文滚动。
- 统一焦点圈、Tab 焦点约束、关闭后焦点恢复；Esc / 遮罩只关闭顶层，异步处理中不能误关。关闭嵌套弹窗不解锁底层页面滚动。尊重减少动态效果偏好。
- 右上角 Toast 使用中性面板、状态图标与始终可见的关闭按钮；搜索、设置、图片预览保留适合各自任务的内容布局，共用弹层和交互规则。
