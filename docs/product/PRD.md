## 1. 产品定位、目标与用户

Right Write 是基于 Open WebUI v0.11.2 的大学写作教学平台，服务教师组织任务、学生与 AI 协同写作、教师基于过程证据评阅和复盘的完整教学闭环。

适用对象是大学本科生与任课教师，任务包括学术论证写作、课程论文、文献评析、文献综述、研究计划和个人陈述。产品文案与样例使用大学课程语境。

| 用户   | 核心任务                                                   |
| ------ | ---------------------------------------------------------- |
| 教师   | 建班、布置作业、追踪提交、批改反馈、查看学生成长与教学分析 |
| 学生   | 加入课程班、写作与对话、提交反思、查看反馈、维护成长目标   |
| 管理员 | 管理平台身份和权限、模型及教学配置、跨教师调班和教研导出   |

产品目标是让师生能够独立完成任务与反馈循环，使正文、对话、修改和反思可回看。平台以教学任务与证据支持教师判断，不自动给出作弊结论或替代教师评分。

当前范围包含教学身份、班级、作业、写作工作区、提交批改、成长画像及教研导出。家长端、复杂排课、全量 LMS 替代和教务结算不属于当前核心范围。

## 2. 身份、班籍与权限

- 平台角色 `user.role` 与教学身份分开。教师和学生身份由 `education-teacher`、`education-student` 用户组承载；平台管理员通过管理员角色获权。
- 学生注册必须提交有效班级邀请码；正常配置下校验通过后入班，pending 学生提升为 user。教师注册不要求邀请码，其平台角色跟随实例默认新用户角色；默认 pending 时需管理员批准，已经为 user 时不再等待审批。空库首位管理员的创建适用其专用规则。
- 一个学生只能加入一个班；教师可管理多个本人班级。
- 教师可在本人班级之间转移学生；跨教师调班由管理员处理。既有提交保留在原班，成长画像跟随学生。
- 教师只能访问权限范围内的班级、作业和提交；个人写作空间对教师不可见。
- 学生的任何对话禁止读写记忆，作业对话还禁用检索聊天记录与记忆的内置工具。
- 作业写作区里学生不能改模型参数、不能加自己的系统提示，无论权限怎么配；对话按老师的作业说明和管理员的模型设定进行。从零写作和文献综述在老师允许时可由学生关闭辅导对话思考；段落论证由教师发布固定设置（见 6.3、6.4）。作业项目文件夹由平台维护，学生不能改写或伪造。其余对话按 `chat.controls` / `chat.params` / `chat.system_prompt` 权限由服务端执行。
- 仍拥有班级的教师不能撤销教学身份。当前没有班级所有权转交工作流，不能把学生调班接口当成班级转交能力。

## 3. 页面与工作流程

模型名称由管理员在模型设置页维护，模型 ID 独立保留用于调用。段落论证作业输入框使用当前保存的名称，改名后刷新工作区生效，不要求重新发布辅导配置。显示名不改变作业绑定及冻结证据，也不作为接口隐藏真实模型的安全机制。

教师顶栏为“总览 / 班级 / 作业 / 批改”。班级子标签为“总览 / 学生”，作业子标签为“概况 / 提交与批改 / 本次分析 / 设置”。班级中的作业入口进入全局作业列表并带班级筛选，不维护独立班级作业子页面。

| 使用场景     | 当前入口与结果                                                           |
| ------------ | ------------------------------------------------------------------------ |
| 教师日常处理 | `/teacher` 展示待批改、临近截止、逾期未交、跟进作业和最近提交            |
| 教师批改队列 | `/teacher/review` 与作业内提交页共用 `SubmissionQueue`，使用教师队列接口 |
| 学生作业写作 | `/me/writing` 查找任务，`/assignments/[assignmentId]/write` 编辑和提交   |
| 学生自由交流 | 侧边栏教学入口与写作项目下方的「自由交流」进入普通聊天；输入框上方常驻提示并链接「我的作业」，聊天不计入课程作业 |
| 学生个人写作 | 由管理员按角色开启，学生默认关闭；关闭时保留内容并拒绝访问                |
| 长期成长     | 学生 `/me/writing/growth`，教师班级下学生详情页                          |
| 教研导出     | 管理员 `/admin/education`                                                |

教师流程为建班、管理学生、创建作业、跟进提交、评阅、反馈和复盘。学生流程由作业形式决定：从零写作直接进入编辑；修订初稿先确认基线，再进行诊断、修改、反思和提交。只有实例开启退回且教师执行退回后，才开放下一轮重交。

学生侧边栏顶部固定「我的作业」，不受用户菜单排序或取消固定影响；原「写作」主入口不重复展示，学生首页标题同步为「我的作业」。登录未指定目的地或目的地为根路径时进入 `/me/writing`，平台名称与标志也指向此页；显式作业、聊天、邀请等链接保留原目的地。普通聊天仍使用 `/` 和 `/c/[id]`，新对话按钮与快捷键继续创建自由交流。桌面展开、收起及手机侧栏采用相同入口顺序。自由交流页面显示用途名称，并在新建与已有聊天的输入框上方常驻「此处对话不计入课程作业。完成作业请前往我的作业。」；「我的作业」可点击，提示不可关闭，不进入作业或个人写作工作区。

## 4. 班级管理与导出

- 班级创建后生成邀请码，教师可重新生成。
- 学生页支持添加已注册学生、按用户 ID 或邮箱批量导入、批量移除及在本人班级之间转移。导入返回成功、已存在和失败反馈，不创建不存在的学生账号。
- 班级总览显示作业和学生的提交、批改进度，可进一步查看未提交学生。
- 教师可导出班级 CSV，包含学生姓名、邮箱、作业标题、提交时间、批改状态、分数和总评。该导出服务班级教学管理，允许身份明文，不是管理员教研假名化导出。
- 当前已提供 CSV；旧任务中的“CSV 或 XLSX”需求已由 CSV 满足，不能据此自动新增 XLSX 待办。

## 5. 作业配置与编辑边界

作业包含题目、要求、班级、截止时间、满分、评分维度、作业形式、辅导档位、反思题和适用的读者试读配置。

三类作业的布置流程统一自动保存草稿，移除“保存准备稿”按钮。首次实际编辑后立即保留本浏览器备份，停止输入约 600ms 后串行保存到服务端；只打开页面不产生空草稿。整个表单（含识图、读者试读、评分、反思、思考及适用的 AI 配置）可未填完就保存，不提前把空分数转成 0 或丢弃未完成选项。作业列表展示本人未发布草稿及本浏览器待同步内容，可继续编辑；教师确认后可删除草稿，含试教记录也不阻止删除。确认提示说明草稿无法恢复，试教记录和已保存方案保留，方案仍可用于其他草稿；已发布作业不受影响。取消或删除失败保留草稿及本地备份。状态明确显示自动保存中、已保存或失败；失败保留输入并支持重试，其他账号不读取这份本地备份。

试教时检查题目、要求和 AI 必填项，不以评分与反思未填完阻止试教。正式布置时检查全部发布条件，明确确认后先等待最新草稿保存，再按其版本发布；保存失败或期间继续编辑时不发布。多页面冲突保留本页输入，可另存为独立草稿，不自动覆盖其他页面。草稿不通知学生，已发布作业的 AI 草稿仍须点击“应用新版本”才生效。

- 向多个本人班级发布时为各班建立对应作业；支持从已有作业复制创建新作业。
- 列表支持班级、关键词和派生状态筛选，并按截止、待批改或最近活动排序。“进行中 / 已截止 / 待批改”是列表展示条件，不是作业数据库状态。
- 作业归档字段、接口和页面操作已删除，不恢复 `status`、`archived_at` 或归档入口。
- 教师可编辑题目、要求和截止时间；评分方式、满分及评分维度在学生提交后仍可修改。尚未批改的提交（含暂存批改）使用最新标准；已发布成绩保留批改时的标准，更正成绩仍使用该标准。
- 已布置作业的内容与教学设置修改都必须填写本次修改说明，不以学生是否开始或提交为条件。包括基础信息、班级、类型、评分、反思、识图、试读、思考和教学配置；隐藏／恢复仅调整可见性，无需说明。段落论证的“应用新版本”指应用老师修改后的 AI 辅导配置，也必须说明，并非升级模型或平台。说明去除首尾空白后为 1—1000 字，前后端共同校验。未发布准备稿仍可自动保存，正式应用修改时填写说明。
- 设置页提前提示必填规则，保存时核对差异并填写说明；没有实际修改不发送保存请求。成功后清空本次输入并展示最近修改说明，失败保留修改和说明，取消不保存。
- 已有初稿基线或已有提交时作业形式锁定，前后端均校验。
- 分项模式中维度满分之和等于作业满分，批改总分等于分项和；仅总分模式不要求虚构分项。评分标准变化后暂存分数需重填，评语保留；旧批改页面保存时须核对评分标准，发生变化返回冲突并要求刷新。
- 对无提交且无学生写作会话的作业提供删除；有业务记录时后端拒绝删除，不以恢复归档替代此边界。
- 教师可隐藏或恢复显示作业，已有写作和提交也允许隐藏；教师列表将显示中与已隐藏的作业分组，隐藏行使用灰色。学生的作业列表、最近写作、项目入口、通知及成长画像作业明细不再展示隐藏作业，旧写作链接与写入请求拒绝访问。已有稿件、提交、成绩和教师批改权限保留，恢复显示不改变截止与定稿规则。
- 教师可催交、为单个学生设置或撤销延期。有效截止时间优先使用个人延期，再使用适用的退回截止，最后使用作业截止。

## 6. 作业形式与 AI 辅导

管理员在模型编辑页通过“备用模型（可选）”选择另一连接的直连模型，选择“无”关闭；沿用现有连接凭据，不填写供应商模型别名映射。配置后仅在响应尚未输出时遇到超时（含上游 408/504）切换一次，学生看到“响应较慢，正在自动重试……”。已开始输出或用户取消时不切换；两路均失败仍保留稿件。段落论证的 API 地址、备用线路和连接能力由管理员维护，新请求使用当前设置，无需重新发布辅导版本。教师发布的提示词、教学模型及生成参数保持固定；每次调用记录当时实际的连接与备用设置，历史调用不改写。


`task_mode` 集中登记为 `from_scratch`（从零写作）、`revise_draft`（修订初稿：文献综述）、`revise_argument`（修订初稿：段落论证）。管理员逐教师设置可布置类型及默认类型，可全部取消；创建、复制与跨类型更新都校验授权，撤权不影响管理既有作业。新教师默认仅从零写作，段落论证必须显式授权。

三类分别维护版本化辅导提示词、默认说明、默认评分和默认反思。教学目标与判断标准合入辅导提示词，在同一个字段维护，不再单独配置或注入。文献综述和从零写作保存教学配置快照，沿用原有采用模板边界。段落论证使用教师发布的独立辅导版本，可在学生开始后发布新版；新请求按捕获时点切换，历史证据不改写。评分模式支持分项与仅总分总评；分项可改名、改分和增删，单项也可。评分设置和反思不进入修订模型上下文。

段落论证的资料搜索为独立可选能力，默认关闭。管理员配置 DeepSeek 官方连接并开放服务，教师在作业辅导准备稿按作业开启，试教或发布后使用。管理员未开启或服务不可用时，教师准备稿与试教工作台隐藏搜索开关；开启时仅展示开关，提示词独立性、关闭行为及生效规则统一在管理员设置说明。已有配置与历史结果保留。开关不改写辅导提示词，随辅导版本和真实调用冻结；关闭时沿用现有请求路径，不添加搜索规则、工具或检索调用。历史对话中的资料保持不变。开启仅允许按需搜索，不要求每轮找资料；真实检索结果保留来源和网页文字，不将搜索摘要、排序分数或命中结果等同于史料核验。服务不可用时说明未核验，学生仍可按原规则提交。

### 6.1 从零写作

学生直接进入正文编辑与辅导对话。教师可按评分维度配置提交前 AI 读者试读，未开启时不进入该环节。学生可在编辑器里导入 Word / 文本 / PDF 文件，预览核对后插入或明确替换正文；照片则选择“照片转正文 / 插入图片”，按用途直接添加到当前稿并保留原件。导入的文字记为外部粘贴，教师在过程时间线上可查看来源。

### 6.2 两类自主修订作业

- 每位学生的每份修订作业只使用一个持续对话，可多次交流、改稿和隔天继续。作业内不提供新建、复制或独立分支；服务端串行校验首条创建，拒绝额外对话及导入、移入/移出、归档和直接删除等绕过路径。从零写作与普通聊天保留多对话能力。
- 开始前仍可按原规则撤回初稿重新开始；提交后不允许借删除对话重置过程。已有多条对话只通过显式备份后的维护操作清理，保留当前有内容的一条，否则保留最近有内容的一条；提交快照、正文、初稿及成绩不随清理改写。

- 保留文件/图片导入、核对及至少 200 个非空白字符的初稿确认，基线冻结后可直接编辑、讨论与提交。导入格式说明按需悬停、聚焦或点击查看；确认栏固定在面板底部，内容单独滚动。AI 阅读期间显示等待动画，正文暂时只读、提交按钮禁用；完成或失败后恢复。
- 左侧为连续对话，初读、历史阅读和聊天按时间展示，已有内容不折叠替换；右侧保持稿件编辑与提交。删除讨论跳转、展开完整反馈及独立阅读历史入口，来源稿件收进对应阅读消息的更多菜单。
- 初次阅读成功后作为真实 AI 回复进入同一聊天历史，后续提问自然携带，页面仅展示一次；来源稿件继续保存在阅读证据中。初次阅读使用确认稿和统一辅导提示词，教学判断、反馈数量、表达顺序及初读/复看方式全部由该提示词控制。默认提示词仍建议少量具体反馈，管理员可以修改；代码不再强制两处上限或先肯定后提问，支持连续回复。
- 输入框只保留一个发送按钮。稿件相对上次已完成的 AI 阅读发生变化后，显示文字提示：有输入时按原文发送问题并读取当前稿；没有输入或附件时，点击同一个发送按钮（或按发送快捷键）发送“我修改了稿件，请看看这次修改。”。发送前先保存，回复追加到原会话末尾；不自动发送、不要求复看才能提交。保存失败保留输入并停止发送。
- 学生无需逐项处理建议，不修改、不采纳、初读失败或不做复看都可正常提交（进行中的阅读须先结束）。学生表达结束后，助手停止推进新任务。
- 两类修订使用各自完整提示词，不叠加通用辅导档位，不启用提交前 AI 读者试读；文献综述保留综述标准，段落论证采用课堂批注提炼的读法。
- 作业说明提供题目、材料与完成要求；教学方式统一维护在辅导提示词中。代码提供流程阶段、真实稿件与版本，不再叠加隐藏的教学规则。文献综述保留结构化输出和引用校验；段落论证接收可阅读正文，检查空回复和不完整结束。
- 历史清单按冻结事实只读展示，不补造新版阅读记录。尚未提交可主动撤回初稿重来；重交保留最初基线。

### 6.3 当前正文与辅导档位

发送对话前等待正文保存，最多 5 秒，保存失败时提示学生。后端读取最近保存正文；修订聊天每轮只附一次当前稿，复看也只附当前全文，不通过关键词判断意图或自动附旧稿，不再按追问关键词额外附加阅读意见。不依赖静态文件夹提示词或模型自发取稿，也不自动叠加模型默认系统提示词、知识库与默认技能。

写作过程记录正文版本、来源、编辑操作与对话，AI 插入和带来源标记的复制可以进入正文。作业写作中的来源构成比例不常驻展示，只在工作区只读时显示；个人写作可显示构成。AI 澄清追问问答可作为过程证据回看，回答次数不替代教师对提问或反思质量的评分。

辅导档位为 `socratic / balanced / hands_off`，由管理员维护措辞。实例可关闭档位；关闭后只注入任务说明。诊断与辅导不承担教师的正式评分职责。

教学模块每处调用模型都登记为一个 AI 步骤：辅导对话、初次阅读、修改复看、整段复看、读者试读、初稿图片识别、班级论证归纳。思考档位为模型默认 / 关 / 低 / 中 / 高，段落论证的初读、交流和复看共用教师发布的模型与思考；其他类型的平台步骤仍由管理员设定，图片识别默认关闭；其他类型只有辅导对话的档位可由管理员下放给教师按作业设定，再由教师决定是否允许学生逐轮关闭。未开放教师配置的步骤保持统一设置，试跑中关掉通读的思考会明显增加漏判误判。实际档位在提交时冻存，学生可开关时逐条回复记录；模型未标明支持思考控制时按模型默认。管理员还可为每个平台步骤指定模型：不指定时通读、试读用学生所选模型，班级论证归纳用老师所选模型，图片识别必须指定；指定的模型即使学生或老师在聊天里无权使用也照常调用，被删除时回落并在管理员页提示。这两类的辅导对话模型由学生选择；段落论证采用教师固定模型。各步骤实际用的模型随轮次冻存。批改分析顶部汇总本轮模型并按辅导对话、初读、复看、读者试读区分；过程回放在每条 AI 回复旁显示模型标识与已记录的思考档位，中途换模型也分别显示，缺失记录明确标注而不根据当前设置猜补。学生只有一个可用模型时只显示名称，多个模型时提供选择。

2026-11-07 起，教学思考内置默认固定为平台 `medium`，对应 DeepSeek 官方 `high`；平台 `high` 对应官方 `max`，不混用。图片识别仍默认关闭思考。管理员已保存的实例设置需显式调整，不由代码默认值覆盖；已提交轮次的冻结配置与记录保持不变。

## 7. 提交、反思与教师批改

- 截止后仍可开始或继续作业，保存、导入、AI 辅导与提交照常开放；学生列表沿用玫红色卡片及“已超时，仍可提交”标签。提交弹窗提前提示，已超时提交的卡片、历史记录、教师提交队列和批改页显示“超时提交”。
- 超时依据该次提交证据中冻结的提交时间和有效截止时间判定（达到截止即为超时）；个人延期优先于适用的退回期限和全班截止。后来修改期限不改写已交标记；待批改覆盖提交按最新提交时点更新，退回后的新轮独立判定。已批改仍定稿。

- 教师按作业配置单选、多选和文本反思题；必答、可见条件和选项边界由服务端校验。
- 提交冻结作业配置、题目、答案、正文版本、辅导配置，以及已完成的阅读记录或适用的读者试读事实。迟到的模型回复不会改写已交证据。后来修改题目或提示词不改变已交轮次。
- 修订初稿不再询问必然为“是”的 AI 使用题。
- 当前轮未批改时允许修改提交，截止后仍可作答、保存、使用 AI 和提交；正式批改后定稿。历史轮保留稿件、反思、批改和差异。
- 正式批改后，服务端同时拒绝自动保存、版本、来源、编辑操作、修订处理与对话生成；超过有效截止时间不再禁止写入。退回后重新开放写作；个人延期用于判定提交是否超时；已批改稿不会仅因延期解锁。个人写作不受作业定稿限制。
- 教师查看终稿、来源、对话时间线、版本、相邻轮差异及适用的初稿对比，并保存维度评分、总评和过程质量评分。
- 教师默认看提交稿与评分，从「查看写作过程」进入过程回放或版本对照。回放可只看对话、只看修改或交叉查看；交流定位到当时实际供 AI 阅读的稿件，保存节点显示上一步到这一步的变化。对照默认从初稿（从零写作为空稿）到提交稿，也可任选两个已保留版本、逐步查看、筛选期间交流。中间自动保存默认收起，可展开；切换查看方式保留选择与未保存的评分。
- 过程查看只读取本次提交的冻结证据；学生后续改稿不混入，重交后旧页须重新加载。中间保存版本属于当前轮，更早过程通过轮次切换查看。不把每次按键等同一个版本，不猜测缺失稿件，也不把时间邻近推断为采纳了 AI 建议。快捷复看与学生自己填写的说明分别标注，查看过程不改变评分。
- 反思质量仅在本轮有实际回答时由教师给 1—5 分；仅有空选答或无反思时不适用。本轮有实际学生提问才评提问质量，平台自动消息不计入。未评分保持空值，不用反思字数或提问条数生成假分。
- 保存批改须同时匹配查看时的稿件版本、评阅版本和评分标准；学生重交、另一标签更正或待批改评分标准更新后拒绝旧页面覆盖。已发布批改只能保存更正或显式退回，不能降回草稿。每次保存追加包含评分标准的评阅事件，正式成绩、画像和导出使用同一已发布版本；未发布草稿不进入成绩。提交时的配置与过程证据保持原样，批改使用的评分标准独立保存。
- `pending / reviewed / returned` 为提交批改状态。退回由 `education.enable_return` 控制，默认关闭；前端隐藏相关操作和统计，后端在关闭时拒绝请求。
- 启用退回时必须填写未来的重交截止时间；学生修改后提交新轮，原轮记录继续保留。
- 作业发布、提交、批改、退回和催交经站内通知形成闭环。

## 8. 提交前 AI 读者试读

辅导助手与读者试读分开呈现。辅导助手提供写作帮助，其内容可经插入或复制进入正文；读者只引用原文提出疑问，让学生自己回应，不代改正文、不预测成绩。

- 教师只对从零写作作业启用试读，设置 2 或 3 轮，并从评分维度选择 1—2 个焦点。
- 提交流程为契约声明、有限回合问答、收尾清单、返回修改或继续提交、反思、提交。
- 回合、顺序和并发状态由服务端约束；学生可跳过，开始前和开始后的跳过均留痕。
- 质疑必须引用原文片段，学生可回看完整往来，清单可定位正文；不在编辑区设置常驻高亮。
- 教师并排查看被引用的原文、学生回应及终稿中的对应内容。片段变化只是一项核查线索，等效修改可能发生在别处，不能自动判断对错。
- 质疑文本与正文快照由服务端冻结；学生回应是学生输入，来源采集的完整度说明与这两类事实应区分解释。
- 不引入 AI 判断“学生是否真正回应了质疑”的结论字段。既有否决继续有效：读者承担提问，教师作评价，避免把可争议判断固化成学生不能答辩的结论。
- 在实例启用退回且作业适用试读时，教师可要求下一轮就退回意见追问，意见在本轮试读开始时冻结。

自适应焦点仍属于待课堂观察的假设，不进入实现排期。应先观察轮转是否足够、学生是否愿意回应、质疑是否落在选定维度；不能借此引入已否决的自动质量判定。

## 9. 本次分析、成长画像与教研

### 9.1 本次分析

提交列表读取教师队列。教师逐份查看来源、编辑突增、对话与修订事实；不在班级或作业层面加总风险，不显示消化度或平均改写率。

作业分析可以聚合读者试读维度与修订初稿的首轮通读处理情况。教师主动触发的未解决论证类型归纳使用输入哈希缓存、最小样本门槛和无直接身份字段的模型输入；只用于教学讲评，不评价班级“好坏”。抽样核对模型问题是否确实落在所选维度，偏离时先调整提示词。

### 9.2 学生成长

教师和学生复用成长画像组件，呈现产出、过程投入、修订深度、AI 协作、教师评分、趋势与轮次进步。成绩保留原分和满分，也提供用于比较的百分比；不能把不同作业满分的原分直接混作同一量纲。

提问与反思质量依赖教师评分，提问数量只作参考。学生可维护成长目标，教师可维护私有观察笔记及修订记录。公式、阈值和内部算法口径信息只在适用的教师视图展示，不把它们作为学生刷数路标。

画像事实证据冻结保存，指标与聚合结果按算法版本形成投影。普通 GET 读取投影，不扫描原始历史或偷偷重算；改算法提升版本，重算走显式入口。首轮过程从声明初稿起算，重交轮从上一轮终稿起算，不把整份初稿当作一次大段突增。

### 9.3 管理员教研导出

按班级和提交时间范围导出 ZIP，包含提交指标、轮次进步、反思题与回答记录及口径说明。学生 ID 使用服务端密钥 HMAC 假名，不导出账号的姓名邮箱字段；不能把假名化误写成彻底匿名化。

指标记录携带算法版本与代码校验和，反思回答的自由文本默认不导出，显式开启 `include_text` 后才带文本；题目快照与选项用于统计。反思记录按提交时冻结的自定义题目输出，已经不使用固定四段反思 schema。空值保持为空，区分未评分、缺失和不适用。

## 10. 管理员实例配置

管理员逐教师维护类型授权与默认类型，并为三种类型分别维护版本化教学配置、默认说明、评分与反思；从零写作保留辅导档位，平台统一维护退回开关、读者试读提示词和各 AI 步骤模型及思考档位。修订辅导提示词固定在作业快照中，教师评分不进入模型。

已有默认维度、复制作业和复用既有反思题的能力，不等同于已经提供独立评分模板或量纲库。模型可见性、直连、工具权限及角色能力也属于实例配置；排障先检查这些条件，再判断实现缺陷。

- 前后端配置与凭据分开，教学界面走国际化文案；桌面写作优先，并保证基础移动端可访问。

- 教师协同评阅和校内系统集成，属于较远期方向，不在当前基础功能内。

## 2026-11-07 配置变更与一致性补充

教师修改已布置作业的内容或教学设置时须填写修改说明；隐藏／恢复显示无需说明。保存前核对差异与受影响人数。要求、截止、评分或反思更新通知学生；后续修订调用直接使用最新作业要求；版本及修改说明保留在对应记录，不向模型追加旧要求或变更提醒。提交弹窗刷新配置，携带配置版本，遇到变更需重新核对；只保留题干、选项和要求仍相同的答案。更新、隐藏／恢复、确认基线、提交与批改按作业串行校验，避免并发绕过锁定。

退回开关继续默认关闭。本次实现与迁移不自动开启真实实例。开启时，退回意见保留在批改与提交证据中，不自动注入修订 AI 上下文；私人笔记与未发布草稿也不进入；更正意见通知学生，重交仍自主决定。

实施与验证状态见 [本轮验证记录](../development/2026-11-07-revision-validation.md)。

## 2026-11-09 按角色配置个人写作

管理员在「设置 → 写作辅导 → 个人写作」分别勾选「允许学生使用个人写作」「允许教师使用个人写作」并保存。学生和教师均默认关闭（2026-11-10 调整）；管理员始终可用。管理员开启对应角色后显示写作入口。关闭角色的个人写作分段、侧边栏项目及首页最近个人稿件隐藏，服务端拒绝新建、打开、编辑和新发起的个人写作 AI 对话（403）。已有稿件和对话保留，重新开启即可继续使用；作业写作、提交、批改和成长画像不受影响。设置保存在当前实例数据库，保存后新请求立即生效，无需重启；其他用户刷新页面更新入口，已经开始的生成不会被中断。

### 6.4 段落论证的教师试教与辅导版本（2026-11-07，本地实现）

- 管理员维护推荐提示词和独立教学模型清单。教师编辑完整提示词副本，并选定一个模型及思考设置用于初读、连续交流与复看。模板后续更新不覆盖副本。学生不覆盖模型、思考或系统提示。
- 准备稿保存完整表单，与正式 Assignment 分离；班级、截止时间可以留空。列表可恢复准备稿。进入试教前必须保存成功；题目、要求和有效 AI 配置是试教的必要输入。
- 试教是教师私有工作台：直接编辑题目、要求和完整提示词，选择 1—3 个教学模型并行比较，分别延续各自对话。改稿后通过普通消息交流，移除试教整段复看、提交预览、评价和调用记录界面；每个模型框可收起／展开，折叠不停止生成。可从本人已完成节点比较新方案。每列只提供“保存方案”，命名保存实际使用的配置；在下方“已保存方案”中可再次测试或“用于作业”；新建准备稿可明确连同题目要求采用，已有作业仅采用 AI 配置，不改班级、评分、反思或截止。保留、采用和发布分开。
- “正式布置”将保存的准备稿一次性发布到所选班级，每班一个作业和 v1；发布前展示模型、思考和真实试教覆盖，允许未试教发布。作业开始后通过“应用新版本”追加 v2、v3；回退也产生新版本，不覆盖旧版本。
- 正式与试教共用请求构造、模型绑定、供应商参数转换、全局过滤器及结果处理。隔离个人记忆、模型默认系统提示、知识库、默认技能、个人过滤器设置和额外工具。教学模型授权不要求开放学生普通聊天；模型删除、停用、底模失效或教学撤权时明确失败，不自动换模型。
- 发布与调用捕获共用作业锁；每个会话的调用有严格顺序。已经捕获 v1 的生成及网络暂时性错误重试保留 v1，新请求捕获 v2。学生重新进入或继续交流时看到更新说明。既有截止、定稿、类型限制及已发布成绩的评分标准继续有效。
- 提交冻结所有已完成调用及其实际使用的辅导版本，使用独立 `teaching_evidence` schema `2026-11-07.1`；教师可查看每条请求、参数、原始输出和版本。准备稿及试教不写入学生提交、成绩、通知和画像。

真实模型试用是教师判断材料，不是自动教学质量认证。当前本地验收结果与未完成项见 [实现方案的验收记录](../development/教师AI试教与作业辅导配置第一版实现方案.md#12-本地实施与验收记录)。

2026-11-08 补验：教师与学生桌面、390px 窄屏流程已完成本地浏览器验证。准备稿恢复期间禁止早于恢复完成的编辑；无关发布字段变化不影响 AI 试教依据。应用代码更新不会使已发布辅导版本停止服务，但旧试教依据须重新验证；空白模型回复不得计为成功试教。跨版本提交之后发布新版本，原提交证据保持不变。


2026-11-08 试教失败展示补充：模型卡明确区分超时、初读格式检查失败、停止和未开始，重新打开仍保留原因；切换测试保留已获取的回复。失败记录不自动改为成功，不自动再次调用或更换模型。


2026-11-08 段落论证初读输出调整：试教和正式作业的初读直接接收反馈正文，支持普通文本、Markdown、表格及正文中的引号，不要求模型输出固定 JSON 字段。程序将全文存入阅读记录并写入真实对话；不因 JSON 语法或逐字引文匹配失败重跑反馈。空正文、明确截断或过滤中断仍显示失败。此调整不改变其他作业类型的阅读协议，不修改历史结果，也不保证自然语言引文已经逐字核验。


2026-11-08 试教体验第一轮：宽屏编辑区与反馈并排，可收起编辑区；修改后的配置与实际反馈配置在结果区按需对照，发送限制就地解释。快捷学生问题只填入输入框。方案保存后可直接打开采用确认弹窗，仍使用真实结果配置，采用不发布。模型对比保留不同模型共用提示词；第二轮新增同一模型提示词 A／B 对比，两列共享模型、思考、搜索设置以及样稿与对话起点，各自保留提示词、反馈及可采用的真实配置。

### 2026-11-08 Word/PDF 材料完整读取

所有作业共用结构化图文导入。2026-11-09 本地改造后，段落、标题、基本格式、表格、图片、图注及脚注在同一份连续稿件中呈现；图片上下排列，不模拟原分页和文字环绕。原件、资源和识别记录仍独立保存。PDF 尽量恢复自然段与分栏顺序，扫描页或复杂矢量版式保留原页图；原生文字层可在不开识图的情况下查看并转入正文，不自动重复插入。无法转换的对象明确提示核对原件。

初读、后续对话和复看持续携带已确认材料及读取状态；截图内容不混入学生正文的来源占比。请求提供材料来源与实际读取状态，不自动判断来源真实性或引用质量。未完成识读不成为提交门槛。提交冻结材料和调用上下文，教师在提交正文旁查看该轮原件，不受学生后续附件变化影响。

复杂嵌入对象及旧版 `.doc` 未能解析的部分必须保留缺口并提示补充或另存为 DOCX/PDF；不声称 OCR 能保证所有文字与史料真实性。本次不自动修复历史已丢失材料，也不改写历史评价。

### 2026-11-08 教师控制作业识图

三类作业分别提供“照片转正文”和“AI 读取参考图片”开关，均默认关闭，由作业教师或管理员独立设置，学生不能改动。新建和设置页的“AI 辅导”区域默认展开，折叠入口、动画及保留输入规则不变。新建、复制、准备稿自动保存和发布、设置均保留两项选择。管理员在 AI 步骤中分别配置模型与思考，选择关闭即停用对应的新识别调用；教师只读查看两项平台模型。两项可以使用相同或不同模型，均与辅导模型独立。

上传照片后先选择用途并可调整页序。“照片转正文”在权限和模型可用时逐页转录，文字直接进入可编辑正文，原图收在上传原件中；已有正文保留并在光标处插入，不再要求二次点击插入。空白页、请求失败或中途撤销权限不能返回缺页成功稿，失败保留文件供重试。“插入图片”始终保存原图，不自动调用模型，不把图中文字计为正文；Word/PDF 的嵌入图片也默认保留。启用参考图片识读后，学生在图旁按需读取，结果作为随附材料，明确点击插入才进入正文。无文字参考图可以正常保存和提交。关闭参考图识读排除后续请求中的图片转录附件及直接图片输入，已进入正文的文字、历史对话和提交证据不删除。

平台保留原图、识别文字、学生编辑痕迹和读取状态。辅导的评价标准与表达方式由教师维护的提示词控制；程序不追加“如何判断或归责”的隐形规则，也不自动扩写内置默认辅导提示词。识图预处理的转录指令仅用于独立识图调用，不拼入辅导对话。

### 2026-11-08 统一上传与模型设置说明

学生通过一个“↑ 上传”入口导入文档或图片，继续支持拖拽；一次一个文档或最多 8 张图片，混选/超限在入口就地解释，识图关闭不禁止上传。初稿顶部仅保留标题与一句说明，格式限制、确认稿作为修改起点和撤回重交方法放入“支持格式”。确认前核对与确认后的行为不变。

管理员分别配置“照片转正文”和“AI 读取参考图片”模型；教师按作业独立启用，不能更换平台模型。新建/设置页只读显示模型名称及可用状态；辅导模型继续用于初读、交流和复看。推荐辅导模型只用于准备时预选，已发布辅导版本及提示词不受此次拆分影响。

### 2026-11-09 统一编辑、提交展示和 Word 下载（本地）

初稿核对和确认后的修改共用富文本编辑器；确认前以独立暂存稿保存，含并发版本校验，不计入确认后的修改过程。确认固定完整图文初稿，仍要求至少 200 个非空白正文字符；图片、占位符和未插入正文的转录文字不计入。只有扫描图片时给出补充正文或转换文字的明确说明。

图片、图注、表格与脚注在提交、历史稿和教师批改中按各自保存版本显示。文字、格式与图片位置变化均可形成版本；文字差异和结构差异分开提示。教师保留上传原件入口；学生将原件收进上传记录，明确其不包含在线修改。

学生可以下载当前稿或选定轮次的已提交稿，教师可以下载所阅提交稿，统一输出 DOCX。当前稿先保存并校验与下载请求一致；提交稿读取固定版本，不随当前改稿变化；同轮更新后，旧页面下载须先刷新。图片嵌入文件，保留基本格式、表格、图注、脚注；不附加聊天、AI 反馈或评分。源文件不被覆盖，新 Word 不承诺原件精确分页。PDF 导出、自由版式和 Word 双向同步不在本次范围。

完整方案及本地验证记录见[图文稿件优化方案](../development/图文稿件统一编辑与Word下载优化方案.md)。未经授权不部署 HIT，不回填旧稿已丢失的排版。

### 稿件保存与故障恢复（2026-11-12）

- 学生初稿与写作正文在输入时先写入本浏览器备份，再按原防抖流程保存；按账号、写作会话、初稿/正文和打开页面隔离。备份包含完整编辑文档及适用的来源、待同步编辑记录；图片文件仍由原材料存储保管。本地容量不足明确提示复制全文或下载文字备份。
- 重新打开时先保留服务器稿件，提示选择恢复、下载或放弃本地备份；明确点击“恢复此稿并保存”才继续上传。已批改的稿件仅允许下载备份，不绕过写作权限；仅超过截止时间仍可恢复保存；初稿基线发生变化时不直接覆盖。
- 保存失败区分登录、批改、权限、格式、附件、网络及服务器问题，提供重试、复制、下载和适用的重新登录入口。仅网络、超时、限流和服务器故障自动有限重试；确定性的校验失败停止重试。
- 普通粘贴将逻辑对齐转为编辑器支持的明确对齐，文档内部链接保留文字并提示简化；图片和脚注沿用原材料权限与结构校验。不会为恢复保存而静默删除稿件内容或放宽后端安全校验。
- AI 发送前仍等待最新稿件及过程记录完成保存。失败或超过 5 秒时保留消息、显示保存处理入口；恢复后由学生再次点击发送，不自动发送或使用旧稿。

## 模型运行统计（2026-11-12）

管理员在「数据分析 → 模型运行状况」查看最近 1 小时、24 小时或 7 天的调用次数、最终失败率、尝试失败率、成功调用平均耗时、最终失败影响人数、备用接管及取消次数。模型管理列表展示最近 24 小时失败率及样本量，链接进入运行统计。模型详情按实际模型与连接线路展示失败原因和分页记录，支持进入模型设置。

一次调用与其中的上游尝试分开计数：重试或备用接管后成功只计一次最终成功；主动取消不纳入两种失败率分母。图片识别按页合并重试，各页分别计数；工具循环、后台标题等独立模型调用分别计数。统计表示模型调用的结果，不代表整个教学流程最终成功。只统计已经结束且实际发往模型的调用，不把权限校验拒绝计为模型故障。

当前覆盖服务器统一 OpenAI 兼容聊天适配层（含由此转换的 Responses 请求），涵盖作业辅导、平台评阅、识图等；浏览器直连、独立插件内部请求、向量化和直接调用 `/openai/responses` 不在本期范围。记录保留 30 天；从启用后采集，不补算历史日志。仅存模型、线路主机及不可逆指纹、内部用户标识、时间、状态和分类，不存提示词、正文、密钥或完整连接地址。统计写入失败只记运维告警，不改变教学调用结果。进程异常退出前尚未结束的调用不计入完成统计。
