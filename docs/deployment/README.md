## 路径与使用范围

原文中的服务器命令从对应服务器目录执行；`deploy/deploy.sh`、本机 `.ssh`、`哈工深批注/` 等路径来自外层工作区。部署工具、SSH 配置、密钥和课程批注材料本次没有迁入本仓库；不能假设克隆本仓库即可运行所有实例操作。

原文中的 `本地开发启动流程.md` 对应上方本地开发文档，`哈工深修订初稿方案.md` 对应上方历史方案链接。

仅在明确的部署任务中使用这些记录，执行前核对目标实例、管理员配置和迁移要求。文档中的历史清表操作不代表新的清表授权。

文档只保存配置占位符。实际环境文件、密码、API Key、SSH 私钥、数据库和备份保持在仓库之外。
